# Kivora

Kivora is a local-first celebration planner built with TanStack Start, React, and TypeScript. It currently stores workspace data in this browser using `localStorage`; no Supabase connection is needed to run the planner.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:8080`). Data stays in that browser profile. Use **Settings → Download workspace backup** to export a JSON copy before clearing browser data.

## Current local features

- Create and edit events, including date, location, expected guests, budget, and currency.
- Event overview, task timeline, budget items with planned and actual amounts, guest list and local RSVP status, vendor research and quote tracking, event-day run sheet, inspiration notes, and local collaborator role labels.
- Calendar view, overdue-task reminders, browser persistence, and JSON workspace backup.
- A planning assistant that creates editable starter checklists from event type and a short brief. Suggestions are rule-based and are not generated by an AI service.
- Query-string deep links for the selected event and event section.

## Deployment

The build is configured for the Vercel Nitro preset. `npm run build` produces the Vercel output, and `vercel.json` marks the project as TanStack Start. Connect the repository to Vercel and use the generated build settings.

## Important limits

Local browser storage is specific to one browser profile and is not suitable for sensitive event records. This local implementation does not provide account authentication, cross-device sync, backend-enforced permissions, real shared collaboration, email invitations, guest-facing RSVP links, or an external AI service. Those features need a server-side data/auth provider and corresponding credentials before they can be production-ready on Vercel. Vendor entries are planner-entered; Kivora does not provide verified vendor listings or prices.
